Smart Lab Equipment Tracker

A web-based laboratory equipment management system built using the MERN stack. It helps manage laboratory equipment, track availability, borrowed equipment, and maintenance status.

🚀 Features
📊 Dashboard with equipment statistics
🔧 Add and manage laboratory equipment
🔍 Search equipment
🟢 Track equipment availability
🟠 Track borrowed equipment
🔴 Track equipment under maintenance
💾 Store equipment data using MongoDB
🔗 React frontend connected to Node.js/Express backend
